## 工作原理

无需编码，无需等待。

你描述你想要的，它就出现了。

每个程序都在运行时生成、编译和执行。

## 什么是 pneuma

pneuma 是一个 AI 原生计算环境。无需安装预构建的应用程序，你只需用自然语言描述你想要的——计算器、仪表盘、游戏——一个可运行的程序就会被生成、编译为 WebAssembly 并在你的 GPU 上执行，只需几秒钟。每个 agent 都在沙盒线程中运行，具有基于能力的权限。没有依赖项、没有供应链、没有安装步骤。软件只在你需要的时候存在。

## 为什么选择 pneuma

### 即时软件

描述你想要的。一个可运行的程序在几秒钟内出现——在你的机器上原生生成、编译和运行。

### 默认沙盒化

每个 agent 都在 WebAssembly 沙盒中运行，内存限制为 64 MB。没有文件系统访问，没有网络访问——除非你批准。

### 零依赖

每个 agent 都是一个独立的 Rust 程序。没有 npm，没有构建工具，没有供应链。源代码可检查且可读。

### 原生性能

编译为 WebAssembly，使用 wgpu（Vulkan/Metal/DX12）渲染。纯 Rust 桌面应用——没有 Electron，没有浏览器引擎。

## 常见问题

### 什么是 pneuma？

pneuma 是一个 AI 原生操作系统，软件由自然语言提示生成。你描述你想要的，一个可运行的程序就会用 Rust 编写、编译为 WebAssembly 并在带有 GPU 渲染的沙盒线程中执行——一切只需几秒钟。没有预安装的应用程序。

### pneuma 是如何工作的？

你输入一个描述你想要的自然语言提示（例如「做一个计算器」）。一个 LLM 编写一个 Rust 程序，代码被编译为 WebAssembly，并在带有 wgpu GPU 渲染的沙盒线程中运行。如果编译失败，系统会自动带着错误上下文重试。整个流程只需几秒钟。

### pneuma 是免费的吗？

是的。免费版每天可生成 10 次，每月 30 次。Pro 版 $5/月，包括每天 100 次生成、agent 编辑和优化、发布到 agent store 的能力以及优先生成队列。

### pneuma 支持哪些平台？

pneuma 可用于 Windows、macOS（Intel 和 Apple Silicon）和 Linux。它是完全用 Rust 编写的原生桌面应用——没有 Electron 或浏览器引擎。

### pneuma 使用安全吗？

每个 agent 都在 WebAssembly 沙盒中运行，具有 64MB 内存限制和基于能力的权限。Agent 无法直接访问你的文件系统、网络或硬件——所有 I/O 都通过经过能力检查的系统 agent。每个 agent 的源代码都可以检查。

### pneuma 与 ChatGPT 或 AI 编码助手有什么不同？

ChatGPT 生成文本。像 Copilot 这样的编码助手帮助开发者更快地编写代码。pneuma 生成正在运行的软件——当你要求一个计算器时，你得到的是在 GPU 上渲染的真实编译程序，而不是代码片段。目标用户是任何能描述自己想要什么的人，而不仅仅是程序员。

### 我能用 pneuma 构建什么？

任何适合屏幕的东西：计算器、仪表盘、游戏、时钟、笔记应用、数据可视化工具、API 监控器、聊天界面、加密货币追踪器、待办事项列表等等。Agent 可以发出 HTTP 请求、持久存储数据、播放音频，并通过 IPC 相互通信。
