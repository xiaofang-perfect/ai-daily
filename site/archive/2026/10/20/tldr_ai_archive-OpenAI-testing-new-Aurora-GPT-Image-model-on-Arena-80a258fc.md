If fresh leaks and tests are anything to go by, then it looks like OpenAI might be getting GPT-Image-3 ready. Three new model references, **aurora-red-alpha, aurora-green-alpha, and aurora-blue-alpha**, briefly appeared in OpenAI's API this weekend, and within hours they were turning up in blind arena tests producing images.

We caught the names through an alert on the [Dev Mode Discord](https://discord.gg/DevMode?ref=testingcatalog.com) server. The references were pulled shortly after, which looked like an accidental rollout.

Lumina soon highlighted that all three models appear to be image models currently tested on [Arena](https://arena.ai/?ref=testingcatalog.com). They even shared a second cat from aurora-green-alpha. Of course, two cat portraits won't tell anyone much about quality, but both look clean and detailed. Still, based on the images we've seen so far, none of them look like they'd make you write home about.

OpenAI testing multiple models isn't exactly a surprise. The company did ship [ChatGPT Images 2.5](https://www.testingcatalog.com/openai-launches-chatgpt-images-2-5-with-faster-editing/) with two API models, GPT-Image-2.5 Flare for speed and GPT-Image-2.5 Sunburst for precision, and it has since been put to work on virtual try-ons in ChatGPT shopping. If you look back further, then we can see that OpenAI ran [three tape-themed Image V2 variants through LM Arena](https://www.testingcatalog.com/openai-tests-next-gen-image-v2-model-on-chatgpt-and-lm-arena/) the same way back in April.

While image generation models are fun to play with, a lot of users are actually waiting for a new frontier model. OpenAI, for its part, recently launched [GPT-6 with Intelligent UI in ChatGPT](https://www.testingcatalog.com/openai-rolls-out-gpt-6-with-intelligent-ui-in-chatgpt/). Before that, we got the company's [Grok Bot and Muse alternative dubbed Dots](https://www.testingcatalog.com/openai-launches-dots-agents-powered-by-gpt-6-astra/), which is currently powered by GPT-6 Astra and GPT-6.1 Sol.

But that's not all.  OpenAI also [listed gpt-rosalind-discovery on its pricing page](https://www.testingcatalog.com/openai-lists-new-gpt-rosalind-discovery-model-in-docs/) last week. That model still hasn't been announced, although Rosalind Workbench opened in research preview a day later.

Meanwhile, Anthropic is [preparing to launch Claude Fable 5.5](https://www.testingcatalog.com/anthropic-several-models-coming-fable-5-5-reaches-partners/), which partners reportedly already have, and Cursor's latest build has started referencing the name. Whether OpenAI answers with GPT-Image-3 or something bigger, the next couple of weeks look busy. There's no documentation or pricing for any of the Aurora models yet, so the cat pics are all we have.
