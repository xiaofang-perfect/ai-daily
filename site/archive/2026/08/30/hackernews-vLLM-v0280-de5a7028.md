# v0.28.0

## Highlights

This release features 584 commits from 270 contributors (76 new)!

- **Kimi-K3 performance push** : a major optimization effort for Kimi-K3 across the stack — Decode Context Parallel (DCP) support ([#50484](https://github.com/vllm-project/vllm/pull/50484) ), fused FlashKDA decode and prefill kernels ([#50654](https://github.com/vllm-project/vllm/pull/50654) ,[#51311](https://github.com/vllm-project/vllm/pull/51311) ,[#52458](https://github.com/vllm-project/vllm/pull/52458) ), SiTU activation support for MegaMoE ([#50510](https://github.com/vllm-project/vllm/pull/50510) ), GEMM-RS for sequence parallelism ([#52079](https://github.com/vllm-project/vllm/pull/52079) ), combined all-gathers with 1.5~3x kernel-level speedup ([#51070](https://github.com/vllm-project/vllm/pull/51070) ), an adaptive speculative token budget delivering ~60% better DSpark TTFT ([#51725](https://github.com/vllm-project/vllm/pull/51725) ), and optional shared-expert sharding saving ~17 GiB of memory per GPU ([#50912](https://github.com/vllm-project/vllm/pull/50912) ). Kimi-K3 also now runs on ROCm with the V2 model runner ([#51653](https://github.com/vllm-project/vllm/pull/51653) ).
- **DeepSeek V4** : sparse MLA now works end-to-end for plain decode, MTP, and DSpark speculative decoding ([#51538](https://github.com/vllm-project/vllm/pull/51538) ), joined by AMD Quark NVFP4 support ([#47972](https://github.com/vllm-project/vllm/pull/47972) ), reasoning-effort prompts and mappings ([#50580](https://github.com/vllm-project/vllm/pull/50580) ), sparse top-k metadata kernel optimizations ([#52084](https://github.com/vllm-project/vllm/pull/52084) ,[#51967](https://github.com/vllm-project/vllm/pull/51967) ), narrowed eager CUDA graph regions ([#51430](https://github.com/vllm-project/vllm/pull/51430) ,[#52401](https://github.com/vllm-project/vllm/pull/52401) ), and ROCm enablement on gfx11 and gfx950 ([#47017](https://github.com/vllm-project/vllm/pull/47017) ,[#52212](https://github.com/vllm-project/vllm/pull/52212) ).
- **Speculative decoding advances** : DFlash2 with local convolution and a candidate selector ([#52816](https://github.com/vllm-project/vllm/pull/52816) ), DSpark confidence-scheduled verification ([#47808](https://github.com/vllm-project/vllm/pull/47808) ), and async scheduling auto-enabled for draft models ([#48341](https://github.com/vllm-project/vllm/pull/48341) ).
- **Model Runner V2 maturation** : E/P/D disaggregation ([#38390](https://github.com/vllm-project/vllm/pull/38390) ), weight offloading ([#51413](https://github.com/vllm-project/vllm/pull/51413) ), multi-layer MTP KV cache support ([#50062](https://github.com/vllm-project/vllm/pull/50062) ), encoder CUDA graphs ([#49852](https://github.com/vllm-project/vllm/pull/49852) ), decoder token-wise pooling ([#50931](https://github.com/vllm-project/vllm/pull/50931) ) plus Transformers pooling models ([#52425](https://github.com/vllm-project/vllm/pull/52425) ), attention-free models ([#52374](https://github.com/vllm-project/vllm/pull/52374) ), and`thinking_token_budget` support ([#46727](https://github.com/vllm-project/vllm/pull/46727) ).
- **Tiered KV cache offloading** : disk offloading support ([#49644](https://github.com/vllm-project/vllm/pull/49644) ), out-of-tree secondary tier managers via`module_path` ([#51007](https://github.com/vllm-project/vllm/pull/51007) ), partial secondary-tier load results ([#50321](https://github.com/vllm-project/vllm/pull/50321) ), tiering metrics ([#48798](https://github.com/vllm-project/vllm/pull/48798) ), and a canonical CPU layout for parallelism-agnostic offload ([#48414](https://github.com/vllm-project/vllm/pull/48414) ).
- **Rust frontend & gRPC** : a standalone renderer ([#50289](https://github.com/vllm-project/vllm/pull/50289) ), multimodal image inference over gRPC ([#50368](https://github.com/vllm-project/vllm/pull/50368) ), explicit data-parallel rank routing ([#51178](https://github.com/vllm-project/vllm/pull/51178) ), and RL lifecycle control ([#51316](https://github.com/vllm-project/vllm/pull/51316) ), with protobuf schemas now published to Buf ([#51276](https://github.com/vllm-project/vllm/pull/51276) ).
- **New defaults** :`max_num_batched_tokens` raised from 8192 to 16384 ([#51726](https://github.com/vllm-project/vllm/pull/51726) ), prefix caching enabled by default for Mamba models ([#50991](https://github.com/vllm-project/vllm/pull/50991) ), and the Blackwell CUDA graph capture default raised to 1024 ([#49390](https://github.com/vllm-project/vllm/pull/49390) ).
- **Breaking changes** : bitsandbytes support migrated to an out-of-tree plugin ([#43529](https://github.com/vllm-project/vllm/pull/43529) ); Transformers bumped to 5.15.0 ([#51668](https://github.com/vllm-project/vllm/pull/51668) ); the deprecated`calculate_kv_scales` runtime KV scale calculation was removed ([#49389](https://github.com/vllm-project/vllm/pull/49389) );`override_attention_dtype` was removed ([#48684](https://github.com/vllm-project/vllm/pull/48684) ).

- **Rust frontend** : a standalone renderer ([#50289](https://github.com/vllm-project/vllm/pull/50289) ), gRPC multimodal image inference ([#50368](https://github.com/vllm-project/vllm/pull/50368) ), explicit data-parallel rank routing ([#51178](https://github.com/vllm-project/vllm/pull/51178) ), RL lifecycle control ([#51316](https://github.com/vllm-project/vllm/pull/51316) ), dynamic tools from developer messages ([#51144](https://github.com/vllm-project/vllm/pull/51144) ), protobuf schemas published to Buf ([#51276](https://github.com/vllm-project/vllm/pull/51276) ), and MiniJinja upgraded to 2.22 ([#51235](https://github.com/vllm-project/vllm/pull/51235) ).

- **Cohere** : upstreamed parser fixes ([#51998](https://github.com/vllm-project/vllm/pull/51998) ), stop sequences reported correctly ([#51556](https://github.com/vllm-project/vllm/pull/51556) ), and vectorized binary embedding bit-packing ([#52277](https://github.com/vllm-project/vllm/pull/52277) ).

## Security

- Fixed a DoS via sample-rate forgery that bypassed the audio decode duration guard ([#49948](https://github.com/vllm-project/vllm/pull/49948) ); the audio decode duration limit is now also enforced in NanoNemotronVL ([#50221](https://github.com/vllm-project/vllm/pull/50221) ).
- DeepStream classified as a GPU backend with pixel limits enforced ([#50755](https://github.com/vllm-project/vllm/pull/50755) ).
- `_load_ov2_processor` guarded with`resolve_trust_remote_code` ([#52952](https://github.com/vllm-project/vllm/pull/52952) ).
- Documentation now warns that `--api-key` does not gate all endpoints ([#51999](https://github.com/vllm-project/vllm/pull/51999) ).
