Google is rolling out “across the board” updates to NotebookLM. The AI-powered note-taking app now uses Google’s upgraded [Gemini 3.5 model](https://www.theverge.com/tech/933699/google-gemini-redesign-ai-3-5-flash-io-2026), which will allow it to respond with “more accurate and reliable information,” according [to a blog post on Monday](https://blog.google/innovation-and-ai/products/notebooklm/better-research-notebooklm/).

[Launched in 2023](https://www.theverge.com/23845856/google-notebooklm-tailwind-ai-notes-research), NotebookLM allows you to interact with your notes and sources using AI, as well as ask questions about the materials. With this update, Google says you can start a research project by just asking NotebookLM questions about a topic, instead of importing notes or YouTube videos. NotebookLM will use Google Search to help you find relevant sources, [building on its “discover” feature](https://www.theverge.com/news/642490/google-notebooklm-discover-sources-ai-audio-overviews) to help you find useful resources on the web.

![You can choose which sources found by NotebookLM to import.](https://platform.theverge.com/wp-content/uploads/sites/2/2026/06/NotebookLM-Sources.png?quality=90&strip=all&crop=0%2C0%2C100%2C100&w=2400)

*You can choose which sources found by NotebookLM to import.*

Additionally, NotebookLM now runs on Google’s agentic coding platform, Antigravity. Each notebook within the app is connected to a “secure cloud computer,” enabling NotebookLM to write and run code to help with your research. NotebookLM can also output information in new formats and file types, including PDF documents, data visualizations (PNG, SVG), Nano Banana-generated images (PNG, JPG, GIF), Excel and PowerPoint files, CSV sheets, and more.

This update is coming to users on Google’s AI Ultra plan and Workspace customers, but the company plans to expand it to more plans in the future.
