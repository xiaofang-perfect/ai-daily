# DeepSeek Code is Coming！

DeepSeek要做自家Code产品这事儿，现在看起来已经不算突然了。

把时间线倒回到几天前。

5月15日，DeepSeek就在自家官方招聘网站上开始「光撒英雄帖」。

在最新热招岗位里，一个名为**Agent Harness产品经理**的职位明晃晃挂了出来：

![](https://i.qbitai.com/wp-content/uploads/2026/05/173feb85a05b2f43082108b361742a16.webp)


3天后，5月18日。

一个名为**Agent Harness研发工程师**的岗位也挂到了社招官网上：

![](https://i.qbitai.com/wp-content/uploads/2026/05/32ba1daffeee9cf83653c38f8c639ea9.webp)


这…其实就很耐人寻味了。

大家也都有感觉，Harness这件事儿，今年在AI圈的存在感已经越来越高。

尤其是当大模型能力开始逼近天花板之后，行业关注点正在从模型本身有多强，转向另一个更现实的问题：

**怎么把模型真正变成一个能稳定干活的Agent。**

而所谓的「Harness」，本质上就是给大模型装上一套可执行、可反馈、可纠错的工作系统。

Agent想在真实任务里持续往前推进，就需要Harness在旁边负责流程编排、工具调用、结果检查、错误回滚。

DeepSeek在官方招聘信息里，也把这层关系概括得很直接——

**Model+Harness=Agent。**

更明显的信号，还藏在Harness岗位的任职要求里：

![](https://i.qbitai.com/wp-content/uploads/2026/05/50b3e91a5d64d311a62ce3eed1432df6.webp)


深度使用过Claude Code、Cowork、Codex、Cursor、OpenCode、GitHub Copilot、Manus、OpenClaw、Hermes等类似产品，并将相关产品的使用融入到自己的工作和生活中。


Claude Code、Codex、Cursor、GitHub Copilot，对应的是AI编程入口。

Manus、OpenClaw、Hermes，则更偏向Agent执行、任务编排和工具调用。

再加上Prompt Engineering、Context Engineering、Harness Engineering这三个关键词，方向已经很清楚了。

DeepSeek想招的，不仅仅是懂产品的人。

而是深度用过AI编程工具、理解Agent工作流、知道模型在真实任务里哪里会卡壳的人。

(Code字辈儿含量简直不要太高啊我说！）

# DeepSeek Code的一些代餐们

估计说到这儿，不少友友已经开始搓手了：

这个所谓的「DeepSeek Code」，到底什么时候能用上？

现实一点说，还得等等…

从目前露出的信息来看，DeepSeek Code更像是刚进入方向成型的阶段。

离真正开放给普通用户使用，可能还要让子弹在天上飞一会儿。

but，这并不耽误我们先找点「平替」尝尝鲜！！

![](https://i.qbitai.com/wp-content/uploads/2026/05/3318a3a01fabf8dea11bc940cafe6555.webp)


我也帮友友们浅浅整理了一些现在就能用的Code系替代品。

首先要说的就是这个月在GitHub上大火、目前已经拿下32.9k Stars的项目：**DeepSeek-TUI**。

它由美国独立开发者Hunter Bown发起，定位也相当直给——

一个DeepSeek版Claude Code。（好耳熟…)

![](https://i.qbitai.com/wp-content/uploads/2026/05/3426b830cf78a72e0a97eefff22f5d1e.webp)


我们可以把它理解为一个用Rust语言编写的TUI编程工具。

它能像Claude Code一样在终端里运行，但也专门针对DeepSeek做了优化适配。

像读**写文件、执行Shell、搜网页、管Git、调度子Agent、接MCP服务器**，这些Claude Code能干活的它基本都能干。

此外也支持安装Skills，只不过换成了DeepSeek V4在背后跑。

不仅如此，作者还给国内用户准备了专门的中文版README文档和专门配置路径，支持TUNA Cargo镜像。

所以如果友友们想提前体验一下**DeepSeek+Claude Code**式终端编程的感觉，DeepSeek-TUI确实可以先拿来试试～

![](https://i.qbitai.com/wp-content/uploads/2026/05/89bdcac6dc8a706ac2a3d474cdbba137.webp)


此外，DeepSeek官方维护的

awesome-deepseek-integration仓库里，还有不少Code相关的工具，也非常值得一看～

比如下面这个**AIMatrices**。

一个用Rust写的、适合快速搭AI应用的低门槛框架，适合想自己快速做出应用工具的开发者。

打包后单个可执行文件只有~40MB左右，能跨平台（Windows/macOS/Linux）用。

像零编写复杂代码，快速构建、部署和维护各种AI应用这些都能干～

![](https://i.qbitai.com/wp-content/uploads/2026/05/1ffcc0585f9c61765b0ad96d9ab24363.webp)


除了电脑端的AI代码编辑器外，一些专门为DeepSeek打造的手机端编程助手也值得一提～

比如下面这个**无思微程序**，它的定位就是DeepSeek移动端编程助手。

其最大的特点就是支持一句话生成小程序、微游戏、微应用。

此外，像**Cursor**和**WindSurf**等主流的AI代码编辑器，也都能很好地集成DeepSeek模型使用，适合在电脑上进行更专业的编程工作。

![](https://i.qbitai.com/wp-content/uploads/2026/05/3916b2c2e944138a33b22e0021eeeb54.webp)
