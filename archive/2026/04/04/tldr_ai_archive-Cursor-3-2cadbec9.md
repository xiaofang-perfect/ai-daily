# 认识全新的 Cursor

软件开发正在改变，Cursor 也在随之演进。

在过去一年里，我们已经从手动编辑文件，转向与那些编写了我们大部分代码的智能体协同工作。随着我们进入[软件开发的第三个时代](https://cursor.com/blog/third-era)，软件的创建方式还将继续演进；在这个时代，成群的智能体将自主工作，持续交付改进。

我们正朝着这个未来迈进，但要真正实现它，仍有许多工作要做。工程师们仍在对单个智能体进行事无巨细的管理，努力跟踪不同的对话，并在多个终端、工具和窗口之间来回切换。

**我们推出 Cursor 3：一个借助智能体构建软件的统一工作区。** 全新的 Cursor 界面让智能体产出的成果一目了然，帮助您站在更高的抽象层级上工作，同时在需要时也能随时深入查看细节。它更快、更简洁、也更强大，具备多代码仓库布局、本地与云端智能体之间的无缝交接，并可随时切换回 Cursor IDE。

Cursor 3 的新变化

在开始构建 Cursor 时，我们选择基于 VS Code 分叉开发，而不是做成一个扩展，以便打造属于我们自己的使用環境。到了 Cursor 3，我们又向前迈进了一步：围绕智能体，从零开始构建了这一全新界面。

你的所有智能体，尽在一处

新界面原生支持多工作区，用户和智能体可跨不同代码仓库协同工作。

并行运行多个智能体

现在，与智能体协作变得更加轻松。所有本地和云端智能体都会显示在侧边栏中，包括您从移动端、Web、桌面端、Slack、GitHub 和 Linear 启动的那些智能体。

云端智能体会生成其工作成果的演示和截图，供您确认。这就是您在 [cursor.com/agents](https://cursor.com/agents) 上获得的同样体验，现在已集成到桌面应用中。

本地与云端之间交接的全新 UX

我们大幅加快了智能体在不同环境之间切换的速度。

当您想进行编辑并在自己的电脑上测试时，可以将智能体会话从云端移到本地。[Composer 2](https://cursor.com/blog/composer-2) 是我们自研的前沿编程模型，拥有较高的用量上限，非常适合快速迭代。

反过来，您也可以将智能体会话从本地移到云端，这样即使您离线，它也能继续运行，或者让您着手处理下一个任务。这对运行时间较长的任务尤其有用，否则当您合上笔记本电脑时，这些任务就会中断。

从提交到合并 PR

全新的差异视图采用更简洁的 UI，让您能更快地编辑和审查变更。准备就绪后，您可以暂存、提交并管理 PR。

在 Cursor 最佳功能的基础上构建

Alpha 用户告诉我们，他们喜欢 Cursor 3 的一个重要原因，是它将 IDE 中最出色的部分，与我们在以智能体为先的界面中推出的新功能结合了起来。

帮助理解代码的文件

你可以随时查看文件，深入了解代码，并在编辑器中借助完整的 LSP 跳转到定义。

集成浏览器

Cursor 可以使用内置[浏览器](https://cursor.com/docs/agent/tools/browser)打开本地网站、进行浏览，并向其发送提示。

Cursor 应用市场上的插件

浏览数百款可通过 MCP、技能、子智能体等扩展智能体能力的[插件](https://cursor.com/docs/plugins)。支持一键安装，或搭建你自己的[团队私有插件应用市场](https://cursor.com/docs/plugins#team-marketplaces)。

借助 AI 编程的最佳方式

在 Cursor 3 中，我们已经具备了模型、产品和运行时这些基础能力，可以构建出更自主的智能体，并提升团队间的协作。我们也会继续投入 IDE，直到代码库能够实现自我驱动。

这不会是软件开发界面最后一次发生变化。更强大的编程模型将解锁新的交互模式。我们很高兴继续构建、简化并不断革新 Cursor，让它成为借助 AI 编程的最佳方式。

升级 Cursor，然后输入 `Cmd+Shift+P -> Agents Window`

来试用新界面。或者前往我们的[文档](https://cursor.com/docs/agent/agents-window)了解更多。
