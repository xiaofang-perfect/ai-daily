# 刚刚，ChatGPT免费版史诗升级！GPT-5.6可以无限白嫖了

Chat优化版

Jay 发自 凹非寺

量子位 | 公众号 QbitAI


GPT-5.6终于可以无限白嫖了。

刚刚，ChatGPT免费用户迎来一波史诗升级，默认模型现在换成了**5.6 Luna**。

关键是，**Chat模式再无次数限制，可以随便薅。本周内会陆续推送。**

Plus和Pro用户也有福利。

Chat中的**5.6 Sol**获得了一波专精升级，官方称其在事实准确性和回答质量上均有明显提升。

![](https://i.qbitai.com/wp-content/uploads/2026/08/ecd80f08f3943aeb5310482257631fd1.png)

好你个奥特曼，原来还记得ChatGPT前缀里有个Chat啊！

不过，此次GPT-5.6 Sol的更新仅限ChatGPT中的聊天体验，**Work和Codex中使用的GPT-5.6 Sol版本不在本次更新范围内。**

# GPT‑5.6 Sol，Chat优化版

Coding热辣滚烫，但事实上，大部分人的使用场景仍然是Chat。

OpenAI表示，每周有**10亿人**通过ChatGPT进行快速问答、网页搜索、规划、研究、咨询和复杂决策。

他们此次更新GPT-5.6 Sol，正是为了更好覆盖这一整条使用光谱。

更新后的GPT-5.6 Sol回答更聚焦，能根据问题调整详细程度，避免不必要的格式堆砌，并且在单纯附和并无帮助时给出有益的纠正。

对Plus和Pro用户而言，**同一模型同时驱动即时回答和深度推理**，体验更加一致。

具体而言，对于快速提问，它给出直接回答并附上必要上下文。对于多步规划、研究或写作等更复杂的任务，则给出更完整的回复，同时保持核心建议清晰。

OpenAI展示了一张对比图来说明新旧模型的差异。在一个骑行咨询场景中，新版本会先回答用户真正关心的问题，识别出风而非雨才是主要影响因素，并只保留骑行者需要的细节信息。

甚至还做了一张**天气预报表**。

![](https://i.qbitai.com/wp-content/uploads/2026/08/c8931fd5e204d4e38aeabb00c5145b69.png)

**幻觉**方面也是少了很多。

在一次针对金融、医疗和法律领域事实性提示的内部评估中，GPT-5.6 Luna的回答中出现至少一处事实错误的比例比GPT-5.5 Instant降低了约**62%**，GPT-5.6 Sol则降低了约**68%**。

除了模型本身，订阅用户还能享受到一波UI体验的更新。

大家都知道，自从5.6三款模型推出来之后，又要选模型，又要选推理强度，常常两眼一黑。

Codex的解决方案呢，是有一个滑块按钮，通过左右滑动可以自动调整智能强度，匹配OpenAI为你默认设置的模型加effort。

**现在这个功能Chat里面也有了！**

![](https://i.qbitai.com/wp-content/uploads/2026/08/df8204bd3df2acb4328c4df94372a86f.png)

Plus和Pro用户可以在网页端、移动端和桌面端通过滑动来调节模型在回答时投入的思考量。日常问题保持快速模式，需要规划、研究、写作、编程或决策时拉高滑块。

对了，免费版用户呢，则会拿到**5.6 Luna的下放**，并且是完全放开，再无聊天限额。

不过嘛，图片生成、文件上传等功能的限额，仍然是保留的。

但官方也知道，虽然说是5.6，但Luna毕竟没那么水桶，所以说专门为她配了一个**新的思考按钮**，用来应对复杂问题。

# One More Thing

不禁很感慨，这几个月来，所有模型都在打Coding，进步也确实非常迅速。

但我们好像忘了，很多人其实并没有生产力需求，他们可能就是想无聊时，跟AI聊聊天。

自从Coding能力提上去之后，生产力是提高挺多的，但也仿佛看着个得了阿尔茨海默症的兄弟，一天天不说人话了。。。

总感觉，**这好像不是个AGI该有的样子？**

近日，字节跳动创始人张一鸣在Seed全员会上的一番发言，也是从另一个角度呼应了行业对包括「Chat」在内的，Coding之外模型能力的再关注吧。

据晚点LatePost报道，**张一鸣**在会上明确表示，编程只是眼下的热点之一，不应该完全被它牵着走，编程之外还有更多更大的机会。他鼓励Seed团队追求智能上限，期待模型能力跻身世界第一梯队。

字节可能是想弯道超车，说这种话倒挺符合直觉的。

但明明已成功跻身硅谷Coding双子星，OpenAI却还记得Chat用户，花精力专门为Chat模式优化模型，确实蛮出乎意料。

可能也跟他们C端用户比较多和**广告商业模式**有关吧。

不过……

Codex到底啥时候重置啊！！！
